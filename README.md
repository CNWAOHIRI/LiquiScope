# LiquiScope

DeFi liquidation-risk reports as an A2MCP Agent Service Provider on OKX.AI.

- **check** (free): single-chain health factor + risk tier for a wallet.
- **report** (x402-paid): full multi-chain analysis — Aave v3 (Base, Arbitrum, Ethereum) + Compound v3 (Base, Arbitrum), liquidation prices, %-drop-to-liquidation, plain-language summary with per-tier recommendations.

Built for the OKX.AI Genesis Hackathon (Jul 2026). Zero-budget: free RPC tiers, free hosting, no paid dependencies anywhere in the request path.
